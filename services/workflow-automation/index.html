Common questions

What tools does this work with?

Most common ones: Google Workspace, Microsoft 365, QuickBooks, Jobber, HubSpot, Square, calendars, forms and spreadsheets. If it has an integration or an API, we can usually connect it.

Will AI send things without me seeing them?

Only if you want it to. Many owners start with drafts they approve, then let routine steps run on their own.

What happens if something breaks?

We monitor the workflows and get alerted when something fails, then fix it.

Is my data safe?

We use the tools’ official connections, give each workflow only the access it needs and don’t store your customer data ourselves.
